# PathNote — 便筏

自动捕获复制的文件/文件夹路径，以列表形式管理，方便快速访问。

## 使用

| 操作 | 功能 |
|------|------|
| 复制文件/文件夹 | 自动添加到列表顶部 |
| 左键 | 复制该路径到剪贴板 |
| Ctrl + 左键 | 在资源管理器中定位到该文件/文件夹 |
| Shift + 左键 | 标定/取消标定（标定项不受重排序影响） |
| 双击 | 打开文件（默认应用）或文件夹（资源管理器） |
| 右键 | 删除该项 |
| Ctrl + 右键 | 清空所有项（需确认） |

## 标定

`Shift + 左键` 切换标定，标定项显示为浅金色，始终保持在列表固定位置，不会被新路径挤下去。

## 窗口

- 默认 480×760，可拖拽调整大小，不可最大化
- 关闭按钮最小化到系统托盘
- 托盘图标双击恢复窗口
- 托盘右键 → `退出` 关闭程序
- 最小化时捕获新路径会自动弹出（不抢夺焦点）

## 数据

路径列表和窗口位置保存在 `%LOCALAPPDATA%\PathNote\`
