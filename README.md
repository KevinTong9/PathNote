# PathNote — 便筏

自动捕获复制的文件/文件夹路径，以列表形式管理，方便快速访问。

## 使用

| 操作 | 功能 |
|------|------|
| 复制文件/文件夹 | 自动添加到列表顶部 |
| 左键 | 复制该路径到剪贴板 |
| Ctrl + 左键 | 在资源管理器中定位到该文件/文件夹 |
| Shift + 左键 | 标定/取消标定（标定项不受重排序影响） |
| 右键 | 删除该项 |
| Ctrl + 右键 | 清空所有项（需确认） |

## 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| ``Ctrl + Alt + ` `` | 最小化 / 前置 之间切换（全局生效，两个方向都不抢当前程序的焦点） |

- 反引号 `` ` `` 在键盘左上角，配 `Ctrl + Alt` 可左手单手按
- 选它是为了避开 Office / Windows / 常见编辑器以及微信、QQ 的既有热键
- 长按不会连续触发（`MOD_NOREPEAT`）
- 若该组合已被其他程序占用，启动时会用托盘气泡提示；程序其它功能不受影响
- 想换键：改 `Form1.cs` 顶部的 `HotkeyModifiers` 与 `HotkeyVk` 两行即可

## 标定

`Shift + 左键` 切换标定，标定项显示为浅金色，始终保持在列表固定位置，不会被新路径挤下去。

## 灰色条目

目标当前不可达的路径（移动硬盘没插、网络盘掉线、盘符改变、文件已被删）显示为**灰色文字**：

- 左键仍可复制路径文本
- `Ctrl + 左键` 暂时打不开；目标恢复后**下一次点击**即可打开，程序会自动把颜色恢复正常，不需要重启
- 判断发生在点击那一刻（不是轮询），所以插回硬盘后无需任何操作
- 这类条目**不会被自动删除**——程序不会因为"暂时够不着"就丢掉你存的路径

## 窗口

- 默认 480×760，可拖拽调整大小，不可最大化
- 关闭按钮最小化到系统托盘
- 托盘图标双击恢复窗口
- 托盘右键 → `退出` 关闭程序
- 最小化时捕获新路径会自动弹出（不抢夺焦点）
- 最小化或隐藏到托盘后，按全局快捷键即可恢复（见上）

## 数据

路径列表和窗口位置保存在 `%LOCALAPPDATA%\PathNote\`
